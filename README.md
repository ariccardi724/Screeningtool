# ScreeningKiosk-AndroidStudio

Starter Android Studio project for the Vestibular Therapy & Dizziness screening kiosk.

## How to build & install on an Android tablet
1. Extract `ScreeningKiosk-AndroidStudio.zip` on your computer.
2. Open **Android Studio** -> **File -> Open** -> select the extracted `ScreeningKiosk-AndroidStudio` folder.
3. Let Gradle sync finish, connect your Android tablet via USB (with USB debugging enabled) or click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
4. Install the generated APK on the tablet and launch **Vestibular Kiosk**.
